WorldFinder API and Core

Public Maven artifacts and versioned Javadocs for WorldFinder compatibility addons.

Gradle repository

repositories {
    maven { url = uri("https://azashiin.github.io/WorldFinder/") }
}

dependencies {
    compileOnly("fr.asashiin.worldfinder:worldfinder-api:0.2.0")
}

Do not embed the API in an addon. The installed WorldFinder mod supplies it at runtime.
