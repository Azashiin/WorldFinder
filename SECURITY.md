# Security policy

## Supported line

Security fixes are provided for the latest published WorldFinder release line. Older development
snapshots and unpublished builds are not supported.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose player data, execute untrusted
code, bypass server permissions, or compromise a developer's publishing credentials. Use GitHub's
private vulnerability reporting for the `Azashiin/WorldFinder` repository instead.

Include the affected library version, reproduction environment, expected impact, and any minimal
proof of concept. Do not include real credentials, private server addresses, world seeds that must
remain confidential, or data belonging to another person.

Ordinary crashes, incorrect seed-map results, performance regressions, and addon compatibility
problems can use the public issue templates.
